NERSC-HYCOM-CICE Documentation
================================

NERSC-HYCOM-CICE is a coupled ocean–sea ice model developed at the Nansen Environmental
and Remote Sensing Center (NERSC). It combines the HYCOM ocean model with the CICE sea ice model,
coupled via the Earth System Modeling Framework (ESMF).
